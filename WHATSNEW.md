# What's New

This file is updated in every commit. Each entry has a project version and records what changed from the preceding commit. Versions follow semantic versioning; the version in `package.json` and `public/manifest.json` must match the newest entry.

## 0.1.0 — 2026-09-23

Initial project version.

- Added a Manifest V3 Firefox extension with a Chrome-compatible background declaration.
- Added middle-click, modifier-click, and new-window-target detection.
- Added conservative tab-group creation and inheritance through a framework-independent rules engine.
- Added synced settings for triggers, safety boundaries, naming, colour, and collapsed state.
- Added unit coverage, TypeScript, linting, formatting, production builds, and CI.
- Added the complete baseline Community Health and project governance files.
- Added an AI declaration clarifying human ownership, permitted assistance, and maintainer accountability.
