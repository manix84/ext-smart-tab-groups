# Security Policy

## Supported versions

Until the first stable release, only the latest release and the default branch receive security fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include sensitive browsing data in a report. Use GitHub's **Report a vulnerability** private security-advisory feature for this repository.

Include the affected version, browser/version, impact, reproduction steps, and a minimal proof of concept. You should receive an acknowledgement within seven days. Timelines depend on severity and the complexity of a safe fix.

Good-faith research that avoids privacy violations, service disruption, and accessing other people's data is welcome.
