# Governance

Smart Tab Groups is currently a maintainer-led project. Rob Taylor is the project maintainer and has final responsibility for scope, releases, security, privacy, and repository administration.

Decisions should be explained publicly in issues or pull requests when practical. Contributions are evaluated on user value, predictable behaviour, privacy, accessibility, maintainability, browser compatibility, and test evidence—not contributor status.

If the maintainer structure changes, this document will be updated before responsibilities are transferred.
