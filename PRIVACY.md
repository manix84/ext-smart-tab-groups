# Privacy Policy

**Effective date:** 23 September 2026

Privacy is a primary design goal of Smart Tab Groups and its maintainer.

## What the extension handles

To decide whether tabs are related, the extension temporarily handles information already present in your browser, including:

- the opening relationship between a parent tab and a new tab;
- link destinations, tab URLs, and tab titles;
- whether a tab is pinned, private, or already grouped;
- the settings you choose.

## What leaves your browser

Nothing. Smart Tab Groups has no analytics, advertising, telemetry, remote API, tracking pixel, or project-operated server. Browsing information is processed locally in the extension.

Settings are stored with the browser's extension storage API. When browser sync is enabled, the browser vendor may sync those settings under its own privacy policy. Smart Tab Groups does not receive or control that synced data.

## Retention

Opening interactions are held in memory briefly so they can be matched to a newly created tab, then discarded. The extension does not build or transmit a browsing-history database. Settings remain in browser storage until you change them, reset the extension, or uninstall it.

## Permissions

The extension requests access to web pages so it can recognise deliberate link-opening gestures, and access to tab groups so it can update native browser groups. These permissions are used only for the behaviour described here.

## Future changes

Any feature that changes data handling must update this policy before release. The project will prefer local processing and the least privilege practical for its functionality.

Privacy questions can be raised through the repository's support process. Please do not include private browsing data in a public report.
