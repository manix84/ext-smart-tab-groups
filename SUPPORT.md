# Support

Use [GitHub Discussions](https://github.com/manix84/ext-smart-tab-groups/discussions) for questions and usage help. Use the issue templates for reproducible bugs and focused feature proposals.

Before posting, check existing issues, try the latest version, and include the browser name/version and extension version. Do not post browsing history, private URLs, account details, or other sensitive information.

Security and conduct reports must use the private route described in [SECURITY.md](SECURITY.md).
